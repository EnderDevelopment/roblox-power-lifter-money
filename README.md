# Roblox Power Lifter Game

This Roblox script enhances the power lifter game by adding a money system and power lifting mechanics. It includes features like giving money to players based on their lifts, taking money, and checking the player's current money. The script also handles the power lifting mechanics, calculating points based on the weight lifted and giving money to the player accordingly.

## Install

1. Open Roblox Studio.
2. Create a new place or open an existing one.
3. Navigate to the ServerScriptService in the Explorer.
4. Create a new Script and name it `MoneySystem`.
5. Paste the contents of `MoneySystem.server.lua` into the script.
6. Create another new Script and name it `PowerLiftingMechanics`.
7. Paste the contents of `PowerLiftingMechanics.server.lua` into the script.

## Use

- The money system can be accessed through the `MoneySystem` module.
- The power lifting mechanics can be accessed through the `PowerLiftingMechanics` module.
